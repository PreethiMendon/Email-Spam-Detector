# Email Spam Detector

A Machine Learning based Email Spam Detection system that classifies emails as Spam or Ham using Natural Language Processing (NLP) techniques and classification algorithms.

## Features

* Detects spam and non-spam emails
* Text preprocessing using NLP
* Machine Learning based prediction
* User-friendly interface
* Fast and accurate classification

## Technologies Used

* Python
* Scikit-learn
* Pandas
* NumPy
* NLP

## Files

* `app.py` – Main application
* `train.py` – Model training script
* `utils.py` – Helper functions
* `spam.csv` – Dataset
* `model.pkl` – Trained model
* `vectorizer.pkl` – Text vectorizer

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   python app.py

## Project Objective

The main objective of this project is to identify unwanted and malicious emails automatically using Machine Learning techniques.
